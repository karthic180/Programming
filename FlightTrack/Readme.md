# FlightTrack

A modern application designed to track and monitor flight data, status, and schedules.

## 🌐 Live Web Companion
Check out the live site here: [Google Sites Flights Tracker](https://sites.google.com/view/flightstrack?usp=sharing)

## 🚀 Features

* **Real-time Tracking:** Monitor active flights with up-to-date arrival and departure details.
* **Flight Search:** Easily look up specific flights by flight number, airport, or airline route.
* **Modern UI:** Built with a clean, intuitive layout optimized for quick data access.

## 🛠️ Built With

* **Platform:** Google Sites (Web Interface)
